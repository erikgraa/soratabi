⚙️ Data sources

Flight numbers are looked up via adsbdb (open source, no key). Add an optional AirLabs key for a 🛫 live plane position & status. Keys are stored only in this browser.

📡 Around me needs live ADS-B data: it uses your AirLabs key, or a CORS proxy for the open adsb.lol API (no key, see proxy/ in the repo).
